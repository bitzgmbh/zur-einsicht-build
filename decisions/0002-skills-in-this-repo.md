# 0002 Skills live in this repository

- Question: where do the agent skills of the pipeline live?
- Options: in this public repository; in the private bitz GmbH skills marketplace; in a separate public repository.
- Choice: in this repository, under `skills/`. The private marketplace can later install them from here.
- Why: the map's principles say to work in the open and to use open source tools around the work. One repository keeps the log and the code in step.
