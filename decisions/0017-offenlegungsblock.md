# 0017 Der Offenlegungsblock einer Ausgabe

- Frage: Wie sieht der Block "So ist diese Ausgabe entstanden" in jeder Ausgabe aus?
- Optionen: Stichworte, aus den Spuren erzeugt; von Hand geschrieben; später entscheiden.
- Wahl: Stichworte, aus den Spuren erzeugt. Ein Skript liest die Commits der Ausgabe (die Trailer, das Prompts Archiv, die re_gent Schritte) und schreibt fünf bis sechs Stichworte: welche Stufen ein Agent gemacht hat, welche ich, mit welchem Modell. Bei einer Ausgabe ganz von Hand steht genau das da.
- Warum: Prinzip 7: Der Einsatz von KI wird aus den Spuren erklärt, nicht aus der Erinnerung. disclosure-summary zeigt das Muster schon für Pull Requests, der Block ist dieselbe Idee pro Ausgabe. Von Hand wäre ehrlich, aber leicht vergessen.
